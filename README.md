## ✨ About the project

Well-Organized is a colorful and intuitive notes application built with  HTML, CSS, and JavaScript. It was developed to provide a simple way to capture ideas, organize tasks, and keep track of everyday activities.

The application allows users to create, edit, delete, and mark notes as completed, as well as organize them using different colors. Notes are saved in the browser's `localStorage`, so they remain available even after the page is closed or refreshed and are restored when the user returns.

The goal is to combine functionality and simplicity in an accessible interface that works across desktop and mobile devices.

## 🎯 Features

- **Note management:** create, edit, delete, and mark notes as completed.
- **Color organization:** assign different colors to notes to make them easier to distinguish.
- **Local persistence:** save notes in the browser using `localStorage`.
- **Responsive design:** adapt the interface to desktop and mobile screens.
- **Interactive interface:** manage notes dynamically without reloading the page.

## 💻 Run locally

To run the project on your computer, follow these steps.

**1. Clone the repository**

```bash
git clone https://github.com/akarolynna/Well-Organized.git
```

**2. Navigate to the project directory**

```bash
cd Well-Organized
```

**3. Open the application**

Open `index.html` in your browser or use the **Live Server** extension in Visual Studio Code to run the application locally.

## 📚 What I learned

Building Well-Organized provided an opportunity to practice fundamental front-end development concepts, including:

- DOM manipulation and event handling.
- Creating and managing application state.
- Implementing CRUD operations for notes.
- Using `localStorage` to persist data between browser sessions.
- Developing responsive layouts for different screen sizes.
- Organizing interactive functionality with vanilla JavaScript.
